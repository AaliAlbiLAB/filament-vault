Propojení s Prusa Connect & PrusaLink Oficiální API

Jak to funguje: Tiskárny Original Prusa (MK4, MK4S, XL, MINI+, MK3.9, CORE One) ukládají přesnou spotřebu materiálu přímo do G-code a sdílí ji přes REST API. Aplikace umožňuje 2 způsoby automatického odečtu:

1. Přímé načtení G-code (100% spolehlivé, okamžité) Přetáhněte vygenerovaný soubor .gcode z PrusaSliceru. Model z něj okamžitě vyčte přesnou spotřebu v gramech a tiskový čas bez nutnosti nastavování sítě.
2. PrusaLink / Prusa Connect REST API Zadejte lokální IP adresu své tiskárny a API klíč. Aplikace se dotáže na stav tiskové úlohy a po dokončení automaticky odečte spotřebu ze skladu.

Jak provozovat aplikaci na mobilním telefonu

🌐 1. Podmínka pro kameru a mikrofon: HTTPS

Mobilní prohlížeče (iOS Safari, Android Chrome) z bezpečnostních důvodů povolí přístup k fotoaparátu a mikrofonu pouze přes zabezpečený protokol HTTPS.

Stačí soubor filament_evidence.html nahrát na GitHub Pages, Netlify Drop nebo Vercel.

📱 2. Přidání na plochu telefonu (PWA mód)

  • iPhone (Safari): Klepněte na ikonu Sdílet (čtvereček se šipkou nahoru) → zvolte „Přidat na plochu“.
  • Android (Chrome): Klepněte na menu se třemi tečkami vpravo nahoře → zvolte „Přidat na plochu“ nebo „Instalovat aplikaci“.

Aplikace se poté otevře na celou obrazovku bez ovládacích lišt prohlížeče jako nativní aplikace.

📸 3. Nativní fotoaparát v dílně

V okně naskladnění použijte tlačítko „📸 Fotoaparát mobilu“, které spustí vestavěný fotoaparát vašeho telefonu i s bleskem a automatickým zaostřováním na štítek.
